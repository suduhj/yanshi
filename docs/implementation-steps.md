# 执行步骤

## 第一阶段

- 初始化 Next.js、Tailwind CSS、TypeScript、ESLint。
- 接入 Prisma + SQLite，创建 Task 模型和初始迁移。
- 建立任务领域测试。
- 实现任务创建、列表、筛选、状态更新、删除。
- 修复中国时间处理，确保新增、编辑、展示、筛选、排序不产生 +8 小时偏移。
- 增加完整编辑页，支持修改任务核心信息、状态、持续推进和下一步动作。
- 取消手动优先级，改为系统按截止时间和完成状态自动判断。
- 首页按“待确认 / 今日必须完成 / 今日要做 / 每日任务 / 持续推进任务 / 其他任务 / 已完成任务”分区展示。
- 打磨表单可用性：新增/编辑失败返回结构化表单状态，展示中文错误提示，成功后显示轻量反馈，删除前确认。
- 项目命名调整为“砚时”，首页展示寓意。
- 增加“今日要做”手动计划，可在新增/编辑时勾选，也可在任务卡片加入或移出。
- 增加“每日任务”，通过当天完成日期记录“今日已完成”，第二天重新出现。
- 增加动态“待确认”和“晨间回砚”，过截止时间的未完成任务先由用户确认，不直接判为逾期。
- 补齐任务卡片处理操作：完成、完成今日、今日推进完成、推迟截止时间、更新下一步和标记整个任务完成。
- 顶部统计卡片和提醒建议支持跳转到对应分类或具体任务，并短暂高亮任务卡片。
- 增加“竞赛任务”类型。
- 接入 DeepSeek 单任务自然语言解析，解析结果只回填新增任务表单。
- 接入本地轻量提醒建议，覆盖待确认/今天截止、每日任务未完成和持续推进任务缺少下一步动作。
- 接入浏览器通知提醒，用户授权后页面打开期间按中国日期键去重通知。
- 增加 Dockerfile、docker-compose、开发日志脚本。
- 建立 `docs`、`GPT.md` 和每日开发日志维护规范。

## 第二阶段：复盘历史与 AI 回顾

### 2.1 今日小结闭环

- 新增 `TaskEvent` 数据模型和迁移，记录关键任务处理动作。
- 新增任务事件服务，统一写入中国日期键、任务标题快照、事件类型和中文摘要。
- 在完成任务、完成今日、今日推进完成、更新下一步、推迟截止时间、晨间确认完成、未完成加入今日等动作后写入事件。
- 首页增加“今日小结”，展示当天完成、推进、推迟和重新安排的任务。
- “今日小结”提供“生成 AI 回顾”按钮，用户主动触发 DeepSeek。
- DeepSeek 不可用时使用本地规则小结兜底。
- 任务编辑页展示最近复盘记录。
- 暂不接入后台 Agent、Web Push、系统级定时提醒、数据导出导入或备份恢复。

## 后续阶段顺序

- 数据安全与迁移：导出、导入、备份、恢复和迁移前保护。
- 提醒系统升级：更强提醒规则、可配置提醒时间、后台 Agent 或 Web Push，进入前需重新确认范围。

## 第三阶段：单机智能化与数据安全

### 3.1 自动备份

- 新增本地备份模块，导出 `Task` 和 `TaskEvent` 为版本化 JSON。
- 新增备份列表、备份读取、备份校验、恢复和旧备份清理逻辑。
- 新增 `/backup` 页面，支持立即备份、查看备份和恢复备份。
- 恢复备份前二次确认，恢复过程使用 Prisma transaction。
- 将 `prisma/backups/` 加入 Git 忽略。

## 每次任务完成后

- 运行必要验证命令。
- 更新当天 `开发日志/YYYY-MM-DD.md`。
- 如果需求、技术、设计或执行步骤变化，同步更新 `docs`。
- 如果新增重要文件或工作规则，同步更新 `GPT.md`。
