# A1 自动备份设计规格

## 背景

砚时当前已完成第二阶段“复盘历史与 AI 回顾”的 2.1 闭环，任务数据和复盘事件都保存在本地 SQLite 中。后续规划草案建议第三阶段先做 A1 自动备份，为本地数据安全和未来迁云提供基础保护。

本规格只覆盖第三阶段的第一步：本地自动备份。它不引入后台常驻 Agent、Web Push、云同步或系统级定时能力。

## 目标

- 支持用户手动创建本地备份。
- 支持页面打开期间每日首次自动创建一份备份。
- 支持查看已有备份列表。
- 支持从备份恢复数据，恢复前必须二次确认。
- 自动清理旧备份，默认保留最近 7 份。
- 备份文件不提交到 Git。

## 非目标

- 不做云端备份。
- 不做后台定时任务。
- 不做系统托盘、守护进程或常驻 Agent。
- 不做浏览器目录选择器。
- 不做多设备同步。
- 不备份 `.env`、DeepSeek 密钥、SQLite 原始数据库文件或构建产物。

## 备份位置

第一版固定使用项目内目录：

```text
prisma/backups/
```

该目录加入 `.gitignore`。备份文件属于用户本地数据，不进入版本控制。

## 备份文件格式

备份文件使用 JSON，文件名使用中国时间：

```text
yanshi-backup-YYYY-MM-DD-HHmmss.json
```

文件结构：

```json
{
  "version": 1,
  "exportedAt": "2026-06-07T10:20:30.000Z",
  "chinaDateKey": "2026-06-07",
  "tasks": [],
  "taskEvents": []
}
```

字段说明：

- `version`：备份格式版本，第一版固定为 `1`。
- `exportedAt`：导出发生时间，使用 ISO UTC 字符串。
- `chinaDateKey`：导出当天的中国日期键。
- `tasks`：当前所有任务记录。
- `taskEvents`：当前所有任务复盘事件记录。

## 服务端模块

新增 `src/lib/backup/backup.ts`，负责：

- 生成备份 payload。
- 写入备份文件。
- 列出备份文件。
- 校验备份文件。
- 恢复备份数据。
- 清理旧备份。
- 检查并执行每日自动备份。

模块保持服务端使用，不暴露给客户端直接读写文件。

## 页面入口

新增 `/backup` 页面，采用现有工具型界面风格：

- 展示备份说明和备份目录。
- 显示“立即备份”按钮。
- 显示备份列表：文件名、导出时间、任务数、事件数、文件大小。
- 每个备份提供“恢复”按钮。
- 恢复按钮使用浏览器确认，确认后再提交 Server Action。
- 成功或失败通过页面顶部轻量提示展示。

首页可以在后续再加入入口；第一版先保证 `/backup` 可用，避免增加首页负担。

## 自动备份策略

页面打开时在服务端检查当天是否已有备份：

- 如果 `prisma/backups/` 中已有当天备份，不再创建。
- 如果没有当天备份，创建一份。
- 自动备份只在页面请求触发时运行，不后台轮询。
- 创建后执行旧备份清理，保留最近 7 份。

第一版可以在首页加载时触发，也可以在 `/backup` 页面加载时触发。实现时优先选择对现有首页影响最小的方案：在 `/backup` 页面加载时触发，并预留 `ensureDailyBackup()` 给后续首页接入。

## 恢复策略

恢复使用 Prisma transaction：

1. 读取并校验备份文件。
2. 确认 `version === 1`。
3. 校验 `tasks` 和 `taskEvents` 是数组。
4. 删除现有 `TaskEvent`。
5. 删除现有 `Task`。
6. 按备份内容重建 `Task`。
7. 按备份内容重建 `TaskEvent`。

恢复失败时返回中文错误，不修改已提交成功之外的数据；事务内错误整体回滚。

## 错误处理

- 备份目录不存在时自动创建。
- 文件读写失败返回中文错误。
- JSON 解析失败返回“备份文件格式无效”。
- 版本不支持返回“暂不支持该备份版本”。
- 恢复目标文件必须来自 `prisma/backups/` 下的文件名，避免路径穿越。

## 测试计划

使用 Vitest 覆盖领域模块：

- 创建备份时生成符合版本 1 的 payload。
- 备份文件名使用中国日期和时间。
- 列表只返回合法备份文件并按时间倒序。
- 自动备份在当天已有备份时不重复创建。
- 清理逻辑只保留最近 7 份。
- 恢复时拒绝无效 JSON。
- 恢复时拒绝不支持的版本。
- 恢复时重建 Task 和 TaskEvent 数据。

页面和 Server Action 以轻量验证为主，优先保证领域模块测试完整。
