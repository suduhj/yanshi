# 项目需求

## 项目定位

「砚时」第一阶段是本地可运行的 Web App，寓意“于书砚之间，理清每日之事”。它用于统一管理课程作业、成图任务、考试复习、学校活动、团支书任务、竞赛任务和生活杂事。

## 第一阶段范围

- 支持任务创建、列表查看、完整编辑、删除。
- 支持按状态、类型、截止时间筛选。
- 新增和编辑任务时显示中文校验错误，不用错误页中断操作。
- 新增、编辑、删除成功后给出轻量反馈。
- 删除任务前需要确认，避免误删。
- 使用中国时间处理截止时间，用户输入什么时间，保存后就显示什么时间。
- 系统自动判断优先级，不再由用户手动填写。
- 支持“大跨度任务 / 持续推进任务”和下一步动作。
- 支持“今日要做”：用户手动把任务加入或移出今日计划，区别于系统自动判断的“今日必须完成”。
- 支持“每日任务”：每日事项单独展示，点击“今日已完成”只记录当天完成，第二天重新出现。
- 支持“竞赛任务”类型，用于比赛报名、材料提交、作品制作、小组分工、答辩准备和竞赛训练。
- 使用 SQLite 本地存储数据。
- 预留 DeepSeek API 和 Agent/提醒模块入口，但不接入真实主动能力。
- 不做登录系统，默认本地单人使用。

## 任务字段

- 标题
- 类型
- 来源
- 截止时间
- 系统优先级
- 状态
- 是否持续推进
- 是否加入今日计划
- 是否每日任务
- 每日任务当天完成日期
- 下一步动作
- 备注
- 创建时间
- 更新时间
