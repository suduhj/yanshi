# 项目需求

## 项目定位

「砚时」第一阶段是本地可运行的 Web App，寓意“于书砚之间，理清每日之事”。它用于统一管理课程作业、成图任务、考试复习、学校活动、团支书任务、竞赛任务和生活杂事。

## 第一阶段范围

- 支持任务创建、列表查看、完整编辑、删除。
- 支持按状态、类型、截止时间筛选。
- 新增和编辑任务时显示中文校验错误，不用错误页中断操作。
- 新增、编辑、删除成功后给出轻量反馈。
- 删除任务前需要确认，避免误删。
- 使用中国时间处理截止时间，用户输入什么时间，保存后就显示什么时间。
- 系统自动判断优先级，不再由用户手动填写。
- 支持“大跨度任务 / 持续推进任务”和下一步动作。
- 支持“今日要做”：用户手动把任务加入或移出今日计划，区别于系统自动判断的“今日必须完成”。
- 支持“每日任务”：每日事项单独展示，点击“今日已完成”只记录当天完成，第二天重新出现。
- 支持“待确认”：截止时间已经过去但用户尚未确认的任务先进入动态确认区，不直接以逾期压迫展示。
- 支持“晨间回砚”：每天打开时优先提示待确认任务，用户可确认已完成、加入今日、推迟截止时间或拆成下一步。
- 支持任务卡片直接处理任务：普通任务可完成，每日任务可完成今日，持续推进任务可记录今日推进、更新下一步或标记整个任务完成。
- 支持顶部统计卡片和提醒建议跳转到对应任务分类或具体任务。
- 支持“竞赛任务”类型，用于比赛报名、材料提交、作品制作、小组分工、答辩准备和竞赛训练。
- 支持 DeepSeek 自然语言解析单个任务草稿，解析后只回填新增任务表单，用户确认后再创建。
- 支持本地轻量提醒建议，基于待确认/今天截止、每日任务未完成和持续推进任务缺少下一步动作生成提醒。
- 支持浏览器通知提醒：用户授权后，在页面打开期间对当天未通知过的提醒发送浏览器通知。
- 使用 SQLite 本地存储数据。
- 不接入后台常驻 Agent、Web Push 或系统级定时能力。
- 不做登录系统，默认本地单人使用。

## 第二阶段规划：复盘历史与 AI 回顾

第二阶段优先建立一个小闭环：砚时记录关键任务处理动作，并在首页生成“今日小结”。AI 只基于这些历史记录生成回顾建议，不直接修改任务。

### 2.1 今日小结闭环

- 支持记录任务历史事件：完成普通任务、完成每日任务、今日推进完成、更新下一步、推迟截止时间、晨间确认已完成、未完成加入今日。
- 支持首页展示紧凑的“今日小结”，汇总今天完成、推进、推迟和重新安排的任务。
- 支持在“今日小结”中点击“生成 AI 回顾”，由用户主动触发 DeepSeek。
- DeepSeek 未配置或调用失败时，显示本地规则生成的小结，不影响任务管理。
- AI 回顾只生成文本建议，不直接创建、编辑、完成或删除任务。
- 支持在任务编辑页查看最近复盘记录，第一版不做完整分析仪表盘。
- 暂不处理数据导出、导入、备份、恢复、后台 Agent、Web Push 或系统级定时提醒。

## 任务字段

- 标题
- 类型
- 来源
- 截止时间
- 系统优先级
- 状态
- 是否持续推进
- 是否加入今日计划
- 是否每日任务
- 每日任务当天完成日期
- 下一步动作
- 备注
- 创建时间
- 更新时间

## 第三阶段规划：单机智能化与数据安全

### 3.2 数据可视化

- 支持 `/stats` 复盘统计页。
- 支持近 7 天完成、推进和重新安排趋势。
- 支持按任务类型查看当前任务分布。
- 支持按任务来源查看当前任务分布。
- 支持查看最近 10 条复盘记录。
- 第一版不引入图表库，不做复杂筛选和导出。
