# 项目需求

## 项目定位

「大学生 AI 任务管家」第一阶段是本地可运行的 Web App，用于统一管理课程作业、成图任务、考试复习、学校活动、团支书任务和生活杂事。

## 第一阶段范围

- 支持任务创建、列表查看、完整编辑、删除。
- 支持按状态、类型、截止时间筛选。
- 使用中国时间处理截止时间，用户输入什么时间，保存后就显示什么时间。
- 系统自动判断优先级，不再由用户手动填写。
- 支持“大跨度任务 / 持续推进任务”和下一步动作。
- 使用 SQLite 本地存储数据。
- 预留 DeepSeek API 和 Agent/提醒模块入口，但不接入真实主动能力。
- 不做登录系统，默认本地单人使用。

## 任务字段

- 标题
- 类型
- 来源
- 截止时间
- 系统优先级
- 状态
- 是否持续推进
- 下一步动作
- 备注
- 创建时间
- 更新时间
